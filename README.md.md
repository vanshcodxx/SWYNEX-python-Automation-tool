
# SWYNEX Python Automation Tool

## Project Overview
A Python script that organizes files into folders
based on their file extensions.

## Features
- Automatically categorizes files
- Supports documents, images, PDFs and more
- Previews file movements before execution
- Requires confirmation before moving files
- Avoids overwriting files with duplicate names
- Handles common file errors

## Technologies Used
- Python 3
- pathlib
- shutil

## How to Run
1. Install Python 3.
2. Open a terminal in the project directory.
3. Run `python main.py`.
4. Enter the path of a test folder.
5. Review the preview and type `YES` to proceed.

## Safety
Test with a sample folder before using
the script on personal files.

## Learning Outcomes
Practiced file handling, functions, loops,
conditional logic, path management and exceptions.
